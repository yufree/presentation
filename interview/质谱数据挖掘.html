质谱核心原理

把样品分子变成离子，在电场/磁场中按 质荷比 (m/z) 分开，再逐个检测，得到一张「质谱图」。

三个关键步骤

  1. 电离 (Ionization) —— 分子变成带电离子（正离子/负离子）
  2. 质量分离 (Mass Analysis) —— 离子按 m/z 在电场/磁场中飞行路径不同而分开
  3. 检测 (Detection) —— 记录每个 m/z 的离子强度

色谱质谱联用数据

  • 质谱通常搭配色谱来分离混合物
  • 多级质谱可以得到更丰富的分子结构信息
  • 联用离子淌度可以区分同分异构体
  • 色谱质谱联用数据本质是带时序的质谱图（扫描循环）
  • 色谱峰形影响定量

经典非靶向分析工作流

  • 采样 → 前处理 → 仪器出峰 → 标注成化合物 → 效应/通路/网络分析

化学反应有固定的质量差

  • 氧化 = +15.995 Da，无论什么化合物被氧化
  • 去甲基化、加氢、结合反应……都有固定质量差
  • 质谱测的是质荷比 → 反应在质量轴上留下固定质量差的步长

PMD：质谱能测到的反应

Paired Mass Distance（PMD）＝ 任意两个峰的质量差

  • 成对出现的峰，其质量差承载化学反应信息
  • 可以从峰表里直接批量提取，不需要任何标注

化学反应质量差

  • 化学反应: \(S_1 + S_2 + … + S_n = P_1 + P_2 + … + P_m \ (n>=1,m>=1)\)

  • 质量差矩阵

\(S_1\) \(S_2\) ... \(S_n\)
\(P_1\) \(|S_1 - P_1|\) \(|S_2 - P_1|\) ... \(|S_n - P_1|\)
\(P_2\) \(|S_1 - P_2|\) \(|S_2 - P_2|\) ... \(|S_n - P_2|\)
... ... ... ... ...
\(P_m\) \(|S_1 - P_m|\) \(|S_2 - P_m|\) ... \(|S_n - P_m|\)
  • 底物质量差: \(PMD_{S_{k}} = min(|S_k-P_1|,|S_k-P_2|,...,|S_k-P_m|) (1 \le k \le n )\)
  • 反应质量差: \(PMD_R = \{PMD_{S_{1}}, PMD_{S_{2}},...,PMD_{S_{n}}\}\)

反应组学

难点一：去冗余：峰 ≠ 化合物

  • 同位素、加合物、碎片、多电荷……一个化合物产生多个峰
  • 不清理 → 关系网络充满假连接

GlobalStd 算法

  • 思路：利用冗余峰的特征质量差来去冗余

竭泽而渔式分析

难点二：质量差定量

  • 反应涉及一对离子
  • 响应因子不同、变化谱不同 → 不能简单相加

质量差定量

  • 静态 PMD ⇒ 上游/下游调控。 酶稳定运行，变的是底物供应或产物去路。用强度求和定量。
  • 动态 PMD ⇒ 酶层调控。 酶活是变量，底物供应大致不变。用比值定量。

案例：双键反应在肺癌中的变化

  • 反应层面定量能区分疾病状态
  • 不依赖任何化合物标注

四条可迁移的思维方式

  1. 卡住时，先检查“分析单位”——化合物不行试反应，反应不够试网络
  2. 数据驱动——数据生成假说，假说指导实验
  3. 成本意识——学科高速发展需要低成本技术
  4. 任何视角切换都有代价——诚实说出省掉了什么
